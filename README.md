# 설교 쇼츠 메이커 (Sermon Shorts Maker)

설교 영상 하나로 교회 쇼츠(유튜브 쇼츠, 인스타 릴스)를 계속 만들어 내는 프로그램입니다.
모든 처리를 내 컴퓨터에서 하므로 쇼츠를 몇 개 만들든 **추가 비용이 들지 않습니다.**

- 유튜브 링크나 영상 파일만 넣으면 받아쓰기까지 자동
- AI 추천 구간 + 하이라이트 모음 자동 제안
- 원하는 대사를 마우스로 드래그해서 직접 선택
- 무음 구간 자동 삭제
- 템플릿 8종 + 자막 모양 6종, 움직이는 자막, 교회 이름과 로고, 배경음악, 마무리 화면
- 빠른 전체 미리보기, 커버 이미지 저장, 내 서식 저장

## 설치 (Windows 10/11)

### 방법 1. 직접 설치
1. 이 페이지 위쪽의 초록색 **Code** 버튼 → **Download ZIP** 을 눌러 받고 압축을 풉니다.
   (git 을 쓰시면 `git clone https://github.com/jesuswithme/sermon-shorts.git`)
2. 폴더 안의 **`setup.cmd`** 를 더블클릭합니다.
   - Python, ffmpeg 가 없으면 자동으로 설치합니다(winget 사용).
   - 받아쓰기 모델(약 1.6GB)을 처음 한 번 내려받습니다.
3. 바탕화면에 생긴 **설교 쇼츠 메이커** 아이콘을 더블클릭하면 브라우저에 프로그램이 열립니다.
   (검은 창을 닫으면 프로그램이 꺼집니다.)

### 방법 2. AI 에이전트에게 맡기기
Claude Code, Codex 처럼 내 PC 에서 명령을 실행할 수 있는 AI 에게 이렇게 말하면 됩니다.

> https://github.com/jesuswithme/sermon-shorts 이 프로그램을 설치해줘

(claude.ai, ChatGPT 웹 채팅처럼 PC 에 접근하지 못하는 AI 로는 설치할 수 없습니다.)

## 사용 순서
1. **영상 넣기**: 유튜브 링크를 붙여 넣거나 영상 파일을 끌어다 놓습니다.
   - 예배 전체 영상이면 '가져오기 설정'에서 **설교 시작/끝 시간**을 넣으세요. 훨씬 빨라집니다.
   - 받아쓰기는 CPU 에서 영상 길이와 비슷하거나 조금 더 걸립니다. 급하면 '빠르게(small)' 나 '유튜브 자동자막 사용'을 고르세요.
2. **쇼츠 내용 고르기**: 추천 구간이 자동으로 들어옵니다.
   - 오른쪽 대본에서 대사를 드래그해 고른 뒤 '현재 쇼츠에 추가' / '새 쇼츠로 만들기'.
   - 떨어진 구간을 여러 개 넣으면 하이라이트 모음이 됩니다.
   - 문장을 두 번 클릭하면 자막 글자를 고칠 수 있습니다.
3. **더 다듬기**: 템플릿과 디자인을 고르고 '선택한 N개 영상 만들기'.
   - 완성된 영상은 `output` 폴더에 저장됩니다 (영상 1개당 약 30초~1분).

## AI 추천 (선택)
[Claude Code](https://claude.com/claude-code) 가 설치되어 있으면 설교 내용을 읽고 추천 구간과 제목을 붙여 줍니다.
없으면 핵심 단어 기반 자동 규칙으로 추천하며, 다른 기능은 모두 그대로 쓸 수 있습니다.

## 저작권 안내
- 유튜브 영상은 **자기 교회 설교처럼 사용 권한이 있는 영상**만 사용해 주세요.
- 기본 배경음악 3곡은 프로그램이 직접 합성해 만드는 음악이라 저작권 걱정이 없습니다. `bgm` 폴더에 음악을 넣으면 목록에 나오는데, 넣는 음악의 저작권은 직접 확인해 주세요.

## 폴더
- `output/` 완성된 쇼츠, 커버 이미지, 설명글
- `bgm/` 배경음악 (mp3, m4a 를 넣으면 목록에 나옵니다)
- `data/` 가져온 설교, 대본, 작업 상태
